# Starfall Explosions (Fabric)
Standalone Fabric module for Minecraft Java 1.21.11, isolated under `minecraft/starfall-explosions/`.
- Fabric Loader 0.18.1, Java 21, Fabric API 0.141.0+1.21.11.
- Gives a Stellar Controller to a joining player if they do not already carry one.
- Right-click opens the orbital console.
- Four client-side cosmetic presets: Nova Pulse, Aurora Veil, Starfall and Void Ripple.
- Particle visuals only: no TNT, block changes, entity damage, targeting or world destruction.

Build from this directory with JDK 21 and Gradle: `gradle build`.
Output JAR: `build/libs/`. This is an initial source scaffold, not yet a verified release build.
