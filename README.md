# Вася — Learning Cat

Fabric-мод для Minecraft Java 1.21.11. Вася — приручаемый кот-компаньон, который наблюдает за действиями игрока и постепенно учится на них.

## Сборка
- Java 21
- Gradle Wrapper (добавить локально командой `gradle wrapper`)
- `gradle build`

## Управление
- `/vasya` — призвать Васю рядом с собой
- `/vasya status` — посмотреть опыт наблюдений и уровни навыков
- `R` — открыть диалог с Васей
- `K` — открыть меню навыков

## Обучение в текущей версии
- Вася замечает добычу руд и каменных блоков, древесины и растительных ресурсов.
- Он замечает использование печей, коптилен, костров, верстаков и хранилищ.
- За наблюдаемые действия начисляется опыт.
- После нескольких наблюдений в одной категории навык автоматически повышается.
- В диалоге можно спросить, чему Вася научился; меню навыков позволяет посмотреть прогресс и потратить накопленный опыт на дополнительное улучшение.

## Ограничения прототипа
Это первый рабочий слой системы наблюдения, а не полноценный автономный ИИ: Вася пока распознаёт типы действий по событиям Minecraft, но ещё не планирует собственные маршруты и не выполняет самостоятельную добычу/сбор. Прогресс пока хранится в памяти текущей сессии и сбрасывается после перезапуска мира/сервера. Пользовательская модель и текстура кота ещё не подключены.

## Важно
Проект пока не собран Gradle и не проверен запуском в Minecraft. Перед распространением нужно выполнить `gradle build` на Java 21.
